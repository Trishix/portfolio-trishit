# Direction: After dark
Experience mode. A mature Spider-Man-inspired portfolio for interviewers, using Trishit's existing portrait, seven project images, education and social destinations.
The world is night photography and condensed editorial typography: charcoal, muted signal red, pale text; asymmetric project images; precise web geometry. The opening layers a large red name over the edge of the existing portrait. The visitor proceeds from identity to project evidence, skills, education, personal background and contact. A GPU web mesh reacts to pointer forces and springs back; GSAP stages the opening and offers restrained scroll reveals; Lenis handles desktop wheel scrolling. Native scrolling on phones; static web and no entrances for reduced motion.
Existing Next.js 14, React 18, Tailwind 3, GSAP, Lenis. No router migration or extra animation libraries. This is one page, so Barba route interception has no useful route transition to own. Current project assets and factual content are retained. External social posts load on explicit request with direct-link fallbacks.
User-pinned Spider-Man theme takes precedence over generic aesthetic alternatives. Code-led execution, no image generation or approved comp. Concept seed was degraded (no catalog challengers). No numerical claim of award-worthiness.
Validation so far: desktop 1440 and mobile 390 screenshot matrix; no horizontal overflow at 320,390,768,900,1024,1440,1920; all 11 images decode; seven projects present; WebGL and fonts load; mobile menu Escape closes, section anchor closes menu and transfers focus; reduced motion uses auto scrolling.
